# Points de désaccord entre sources secondaires (à trancher sur EUR-Lex)

- Date d'application de l'article 50 (transparence) : une note de la Cloud Security Alliance évoque le 2/12/2026 pour l'obligation de marquage des contenus synthétiques, d'autres sources laissent le 2/8/2026.
- Report conditionné ou non à la disponibilité de normes harmonisées : sources divergentes.

Sources secondaires lues (recherche du 2026-10-29) : natlawreview.com (EU Digital Omnibus AI enters force), Cloud Security Alliance (note sur l'échéance haut risque), Cuatrecasas (Digital Omnibus on AI has been published), FPF (EU AI Act Timeline 2026 R2).

# À faire pour lever le doute

Ouvrir EUR-Lex (CELEX 32026R1744) dans un navigateur, noter la date et copier les articles de dates d'application. Louis peut aussi coller le texte.
