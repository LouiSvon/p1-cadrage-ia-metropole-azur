# Dans le périmètre

- Recherche et résumé de délibérations, règlements, pièces de marchés publics (corpus de documents textuels).
- Utilisateurs : agents internes uniquement.
- Réponses avec citation de la source et du passage.

# Hors périmètre (à justifier dans le dossier)

- Aucun service aux citoyens (pas de chatbot public).
- Aucune décision ou notation de personnes, d'agents ou de candidats.
- Aucune rédaction automatique d'actes juridiques signés.
- Pas de données de santé, sociales ou RH.

# Parties prenantes

| Rôle | Intérêt | Point de vigilance |
|---|---|---|
| Direction juridique et commande publique (porteur) | gain de temps, fiabilité | réponses fausses sur le droit des marchés |
| DSI | hébergement, intégration, sécurité | dépendance fournisseur, fuite de données |
| DPO | RGPD, registre des traitements | données personnelles dans les pièces |
| Élus et direction générale | image, budget | usage public d'erreurs |
| Agents utilisateurs | utilité, charge | confiance excessive, déqualification |
| Syndicats ou représentants du personnel | impact sur le travail | consultation à prévoir (à confirmer) |

# Questions ouvertes (hypothèses de travail, à trancher en semaine 2)

- Hébergement : cloud souverain, modèle local ou API ? Choix traité dans la section Options.
- Les pièces de marchés contiennent des noms de personnes : hypothèse retenue, corpus avec données personnelles possibles (traité en risques).
